# PORTFOLIO WEBSITE

## Chạy trực tiếp
1. Giải nén thư mục.
2. Mở file `index.html` bằng Chrome/Edge.
3. Website sẽ chạy ngay, không cần cài server.

## Chỉnh sửa
- Nội dung: `index.html`
- Màu sắc, font, bố cục: `style.css`
- Hiệu ứng và chức năng: `script.js`

## Thay ảnh sản phẩm
Các ô sản phẩm hiện đang dùng nền màu CSS. Có thể thay bằng ảnh thật trong `index.html`/`style.css`.

## Lưu ý
Form liên hệ hiện chỉ là giao diện. Muốn gửi dữ liệu thật tới email cần kết nối thêm một dịch vụ form hoặc backend.
